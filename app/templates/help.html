Центр помощи

  1. Авторизуйтесь в системе
  2. Перейдите в раздел "Ключи"
  3. Нажмите кнопку "Сгенерировать новую пару ключей"
  4. Дождитесь завершения генерации
  5. Обязательно сохраните приватный ключ в надежном месте!

Приватный ключ не хранится на сервере. При его утере восстановить данные будет невозможно.

  1. Перейдите в раздел "Шифрование"
  2. Введите текст для шифрования
  3. Выберите существующий публичный ключ или используйте временный
  4. Нажмите "Зашифровать"
  5. Скопируйте полученный зашифрованный текст

  1. Перейдите в раздел "Расшифрование"
  2. Вставьте зашифрованный текст в формате JSON
  3. Выберите соответствующий приватный ключ
  4. Нажмите "Расшифровать"
  5. Получите исходный текст

История всех ваших операций доступна в разделе "История". Там вы можете:

  • Просмотреть все выполненные операции
  • Отфильтровать по типу (шифрование/расшифрование)
  • Посмотреть детали каждой операции
  • Скопировать результаты операций

Внимание! Приватный ключ не может быть восстановлен!

Если вы потеряли приватный ключ:

  1. Сгенерируйте новую пару ключей
  2. Все данные, зашифрованные старым ключом, станут недоступны
  3. В будущем обязательно сохраняйте приватные ключи в безопасном месте
